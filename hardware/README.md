# 硬件

现在用的是 **PicoBlock 扩展板**（MAKERDBO / 创乐博）：板子上已经有 4 个按键、蜂鸣器、8 颗 LED、4 颗 RGB 灯，以及 GPIO、3.3V、5V、GND 的排针。只需要另外接一个摇杆模块。

不用扩展板、全用散件接的做法放在后面的[散件 + 面包板](#散件--面包板)。

## PicoBlock 接线（M1）

### 1. 把 Pico 插进扩展板

Pico 要插在中间那两条**黑色排母**里，USB 口朝着印有 `USB` 方框的那一端。插在面包板上的话，扩展板的排针什么都连不到。

插好以后，两边的黄色排针就是 Pico 的 40 个脚，每一针旁边都印着名字，比如 `GP26/ADC0/PWM_A[5]` 和脚位号 `31`。

### 2. 接线（全部用母对母杜邦线，共 9 根）

| 从 | 接到扩展板上的 | 说明 |
|---|---|---|
| 摇杆 GND | 底部黑色 **GND** 排针（任意一针） | |
| 摇杆 +5V | 底部红色 **+3.3V** 排针（任意一针） | **接 3.3V，不要接 5V**。RP2040 的 ADC 脚耐不住 5V |
| 摇杆 VRx | 黄色排针 **GP26**（31 脚） | ADC0 |
| 摇杆 VRy | 黄色排针 **GP27**（32 脚） | ADC1 |
| 摇杆 SW | 黄色排针 **GP2**（4 脚） | 摇杆按下 |
| 方向键排针 UP | 黄色排针 **GP10**（14 脚） | 4 个蓝色按键旁边那排排针 |
| 方向键排针 DOWN | 黄色排针 **GP11**（15 脚） | |
| 方向键排针 LEFT | 黄色排针 **GP12**（16 脚） | |
| 方向键排针 RIGHT | 黄色排针 **GP13**（17 脚） | |

- 底部的 GND、+3.3V、+5.0V 排针各有 4 针，同一排的 4 针在板子内部是连通的，插哪一针都行。
- 板子上的 4 个按键已经自带电阻，并且接好了电源和地，只需要把信号排针接到 GPIO。按下是高电平还是低电平，固件开机时会自动判断（见 `config.py` 的 `BUTTON_MODE`）。
- 摇杆模块上的 5 个脚以模块上印的字为准，顺序不同的模块不一样。

### 3. 板子上还有什么（后面会用到）

| 板载 | 排针标签 | 阶段 | 用途 |
|---|---|---|---|
| 蜂鸣器 | `BUZZER OUT` | M5 | 漏接、得分音效 |
| 4 颗 RGB 灯（WS2812） | `RGBS` | M5 | 显示剩余命数 |
| 8 颗 LED | `LED1`–`LED8` | M5 | 备用指示灯 |
| 光线 / 传感器模块 + 调节电位器 | `Sensor Out` | - | 暂时不用 |
| SWD 调试口 | 排母下方 3 针 | - | 以后用 C SDK 调试时用 |

M5 还要震动的话，需要另外接震动马达和三极管（电路在后面）。OLED 也要另外买。

## 引脚分配

固件里的引脚都在 [`firmware/config.py`](../firmware/config.py)。物理脚位：USB 口朝上、正面朝上时，左上角是 1 脚，左边从上到下 1–20，右边从下到上 21–40。

| 功能 | GPIO | 物理脚 | 阶段 |
|---|---|---|---|
| 摇杆 X | GP26 / ADC0 | 31 | M1 |
| 摇杆 Y | GP27 / ADC1 | 32 | M1 |
| 摇杆按下 | GP2 | 4 | M1 |
| UP | GP10 | 14 | M1 |
| DOWN | GP11 | 15 | M1 |
| LEFT | GP12 | 16 | M1 |
| RIGHT | GP13 | 17 | M1 |
| START（可选） | GP14 | 19 | 可选 |
| SELECT（可选） | GP15 | 20 | 可选 |
| OLED SDA / SCL | GP4 / GP5 | 6 / 7 | M5 |
| RGB 灯数据 | GP16 | 21 | M5 |
| 蜂鸣器 | GP18 | 24 | M5 |
| 震动马达 | GP19 | 25 | M5 |

## M5 反馈电路（扩展板上没有的部分）

### 震动马达

```
GP19 ──[1kΩ]── B  NPN（S8050）
                  E ── GND
                  C ──┬── 马达 −
                      │
                    二极管（阴极/有线的一端朝 3V3）
                      │
3V3(OUT) ─────────────┴── 马达 +
```

- GPIO 每个脚只能安全输出几毫安，马达要几十毫安，所以必须经三极管。
- 二极管并在马达两端，阴极接 +。马达断电时会产生反向电压，二极管把它泄掉，保护三极管。
- 3V 硬币马达接 3V3 就够了。3V3(OUT) 最多给大约 300 mA，一个马达没问题。

### OLED

`3V3 → VCC`，`GND → GND`，`GP4 → SDA`，`GP5 → SCL`。I2C 地址一般是 `0x3C`。

## 散件 + 面包板

不用扩展板时，按键要自己接：每个按键一脚接 GPIO，另一脚接 GND。6 个按键都要接地，所以先用一根线把 Pico 的一个 GND 脚（比如 18 脚）接到面包板边上蓝色 `−` 那排电源轨，再把每个按键的第二脚插到这排孔里。固件会检测到它们是"散装按键"，自动打开内部上拉。

```
摇杆模块               Pico
  GND  ───────────── 33 AGND
  +5V  ───────────── 36 3V3(OUT)
  VRx  ───────────── 31 GP26
  VRy  ───────────── 32 GP27
  SW   ───────────── 4  GP2

按键      一脚 ────── GPIO（见引脚分配）   另一脚 ── 面包板 GND 轨 ── 18 GND
```

6×6 轻触按键有 4 个脚，两两内部相通，接对角的两个脚最保险。有些长面包板的电源轨在中间是断开的，要用短线把两段连起来。

## 安全检查（每次通电前看一眼）

- [ ] 摇杆接的是 +3.3V，不是 +5.0V / VBUS / VSYS
- [ ] 没有任何 GPIO 直接接到 5V
- [ ] Pico 插在扩展板的黑色排母里，方向和 `USB` 标记一致
- [ ] （M5）马达经过三极管，并且有续流二极管
