## 引脚分配

固件里的引脚都在 [`firmware/config.py`](../firmware/config.py)。下表的"物理脚"是板子上从 1 数到 40 的脚位（USB 口朝上，左上角是 1 脚，左边 1–20，右边从下往上 21–40）。

| 功能 | GPIO | 物理脚 | 接到 |
|---|---|---|---|
| 摇杆 X | GP26 / ADC0 | 31 | 摇杆 VRx |
| 摇杆 Y | GP27 / ADC1 | 32 | 摇杆 VRy |
| 摇杆供电 | 3V3(OUT) | 36 | 摇杆 +5V 脚（**接 3V3，不要接 5V**） |
| 摇杆地 | AGND | 33 | 摇杆 GND（用模拟地噪声更小） |
| 旋钮（可选） | GP28 / ADC2 | 34 | 电位器中间脚，两边接 3V3 和 AGND |
| 摇杆按下 | GP2 | 4 | 摇杆 SW |
| A | GP10 | 14 | 按键 → GND |
| B | GP11 | 15 | 按键 → GND |
| X | GP12 | 16 | 按键 → GND |
| Y | GP13 | 17 | 按键 → GND |
| START | GP14 | 19 | 按键 → GND |
| SELECT | GP15 | 20 | 按键 → GND |
| OLED SDA | GP4 | 6 | OLED SDA |
| OLED SCL | GP5 | 7 | OLED SCL |
| WS2812 数据 | GP16 | 21 | 经 330Ω 到灯珠 DIN |
| 蜂鸣器 | GP18 | 24 | 蜂鸣器 + |
| 震动马达 | GP19 | 25 | 经 1kΩ 到三极管基极 |
| GND | GND | 3、8、13、18、23、28、38 | 公共地 |
| 5V（USB） | VBUS | 40 | WS2812 供电 |

按键每个一脚接 GPIO、另一脚接 GND，不用外接电阻，固件开了内部上拉。6×6 轻触按键有 4 个脚，两两内部相通，接对角的两个脚最保险。

## M1 面包板接线

```
摇杆模块               Pico
  GND  ───────────── 33 AGND
  +5V  ───────────── 36 3V3(OUT)
  VRx  ───────────── 31 GP26
  VRy  ───────────── 32 GP27
  SW   ───────────── 4  GP2

按键 A    一脚 ────── 14 GP10     另一脚 ── GND
按键 B    一脚 ────── 15 GP11     另一脚 ── GND
按键 X    一脚 ────── 16 GP12     另一脚 ── GND
按键 Y    一脚 ────── 17 GP13     另一脚 ── GND
START     一脚 ────── 19 GP14     另一脚 ── GND
SELECT    一脚 ────── 20 GP15     另一脚 ── GND
```

面包板的一条蓝色电源轨接 Pico 的 GND（比如 38 脚），所有按键的另一脚都接到这条轨上。

## M5 反馈电路

### 震动马达

```
GP19 ──[1kΩ]── B  NPN（S8050）
                  E ── GND
                  C ──┬── 马达 −
                      │
                    二极管（阴极/有线的一端朝 3V3）
                      │
3V3(OUT) ─────────────┴── 马达 +
```

- GPIO 每个脚只能安全输出几毫安，马达要几十毫安，所以必须经三极管。
- 二极管并在马达两端，阴极接 +。马达断电时会产生反向电压，二极管把它泄掉，保护三极管。
- 3V 硬币马达接 3V3 就够了。3V3(OUT) 最多给大约 300 mA，一个马达没问题。

### 蜂鸣器

压电无源蜂鸣器：`GP18 → 蜂鸣器 +`，`蜂鸣器 − → GND`，固件用 PWM 出声。电磁式（里面有线圈）的按马达那样经三极管驱动。

### WS2812

`VBUS(5V) → VDD`，`GND → GND`，`GP16 → 330Ω → DIN`。只用一两颗灯珠时，3.3V 的数据信号一般能驱动；不稳定的话把 VDD 改接 3V3 试试（会暗一点），或者换 SK6812。

### OLED

`3V3 → VCC`，`GND → GND`，`GP4 → SDA`，`GP5 → SCL`。I2C 地址一般是 `0x3C`。

## 安全检查（每次通电前看一眼）

- [ ] 摇杆和 OLED 接的是 3V3，不是 VBUS / VSYS
- [ ] 没有任何 GPIO 直接接到 5V
- [ ] 马达经过三极管，并且有续流二极管
- [ ] 3V3 和 GND 之间没有短路（万用表蜂鸣档测一下）
